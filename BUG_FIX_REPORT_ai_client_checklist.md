# Bug Fix Report: ai_client_checklist Storage Issue

## Issue Summary
The `ai_client_checklist` field in the `ConsultationRequest` model was not being stored correctly in the database.

## What is `ai_client_checklist`?
`ai_client_checklist` stores **AI-generated recommended questions** that clients should ask their lawyer during the video consultation. These questions are generated by the SALAH AI based on the case details provided by the client.

Example questions:
- "What are my legal rights in this case?"
- "What is the expected timeline?"
- "What documents do I need to prepare?"

## The Bug

### Root Cause
The frontend was sending the questions as a **JSON string**, but the backend was storing it directly without parsing it back to a Python object. Since the database field is a `JSONField`, Django was **double-encoding** the data.

### Data Flow (BEFORE FIX):
1. **Frontend** (`case_brief.html` line 244):
   ```javascript
   // Converts array to JSON string
   document.getElementById("hidden_ai_checklist").value = JSON.stringify(data.recommended_questions);
   // Result: '["Question 1", "Question 2"]' (STRING)
   ```

2. **Backend** (`views.py` line 138 - OLD CODE):
   ```python
   # Receives as string, stores as string
   ai_client_checklist = request.POST.get("ai_client_checklist")
   # Type: str
   # Value: '["Question 1", "Question 2"]'
   ```

3. **Database Storage**:
   - Django's JSONField sees a STRING
   - It JSON-encodes it AGAIN
   - Result: Double-encoded mess: `"[\"Question 1\", \"Question 2\"]"`

### Impact
- The questions were stored as a string instead of a list
- Lawyers couldn't access individual questions programmatically
- Any attempt to iterate over questions would fail
- The data was essentially unusable in its stored form

## The Fix

### Code Changes
**File**: `accounts/views.py` (lines 135-145)

**BEFORE**:
```python
ai_client_checklist = request.POST.get("ai_client_checklist")
```

**AFTER**:
```python
# Parse JSON string to Python object for JSONField
ai_client_checklist_raw = request.POST.get("ai_client_checklist")
ai_client_checklist = None
if ai_client_checklist_raw:
    try:
        ai_client_checklist = json.loads(ai_client_checklist_raw)
    except json.JSONDecodeError:
        ai_client_checklist = None  # Fallback if JSON is invalid
```

### How It Works Now

1. **Frontend** (unchanged):
   - Sends: `'["Question 1", "Question 2"]'` (JSON string)

2. **Backend** (FIXED):
   - Receives: `'["Question 1", "Question 2"]'` (string)
   - Parses: `["Question 1", "Question 2"]` (Python list)
   - Stores: Python list in JSONField

3. **Database Storage**:
   - Django's JSONField receives a Python list
   - Stores it correctly as JSON array
   - Result: `["Question 1", "Question 2"]` (properly formatted JSON)

4. **Retrieval**:
   ```python
   consultation = ConsultationRequest.objects.get(id=123)
   questions = consultation.ai_client_checklist
   # Type: list
   # Value: ['Question 1', 'Question 2']
   
   # Can now iterate:
   for question in questions:
       print(question)
   ```
